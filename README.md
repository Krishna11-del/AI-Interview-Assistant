# AI Interview Assistant

An AI-powered interview preparation tool built using Python, Streamlit, and Google Gemini AI.

## Features
- Upload Resume (PDF)
- Extract Skills Automatically
- Generate AI-Based Interview Questions
- Evaluate Candidate Answers
- Calculate Interview Score
- Generate PDF Interview Report

## Tech Stack
- Python
- Streamlit
- Google Gemini AI
- PyPDF2
- FPDF

## Installation

1. Clone the repository

```bash
git clone https://github.com/Krishna11-del/AI-Interview-Assistant.git
cd AI-Interview-Assistant
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Create a `.env` file

```env
GEMINI_API_KEY=your_api_key_here
```

4. Run the application

```bash
streamlit run streamlit_app.py
              or
python -m streamlit run streamlit_app.py
```

5. Open in browser

```
http://localhost:8501
```
